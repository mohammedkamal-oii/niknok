# niknok
Vertical short-video feed for Android (Kotlin, Jetpack Compose, Media3).
- Swipe to change video, tap to pause, double-tap or tap heart to like, comment, share, progress bar.
- "+ Add" picks videos from your phone.

## Build with GitHub
1. Create a repo, upload everything in this folder (including the hidden .github folder), push to `main`.
2. Open the Actions tab > "Build APK" > wait for green.
3. Download the `niknok-debug-apk` artifact, unzip, install app-debug.apk on your phone.
